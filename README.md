# Tipos de Quadro ASCII/Unicode

## Tipo 1 — ASCII Puro (funciona em qualquer lugar)
```
+----------+
|  texto   |
+----------+
```
Caracteres: `+` `-` `|`

---

## Tipo 2 — Linha simples
```
┌──────────┐
│  texto   │
└──────────┘
```
Caracteres: `┌` `─` `┐` `│` `└` `┘`

---

## Tipo 3 — Linha dupla
```
╔══════════╗
║  texto   ║
╚══════════╝
```
Caracteres: `╔` `═` `╗` `║` `╚` `╝`

---

## Tipo 4 — Misto (duplo horizontal, simples vertical)
```
╒══════════╕
│  texto   │
╘══════════╛
```
Caracteres: `╒` `═` `╕` `│` `╘` `╛`

---

## Tipo 5 — Misto (simples horizontal, duplo vertical)
```
╓──────────╖
║  texto   ║
╙──────────╜
```
Caracteres: `╓` `─` `╖` `║` `╙` `╜`

---

## Tipo 6 — Arredondado
```
╭──────────╮
│  texto   │
╰──────────╯
```
Caracteres: `╭` `─` `╮` `│` `╰` `╯`

---

## Como digitar pelo teclado (Windows)

Você segura `Alt` e digita o número no **teclado numérico**:

| Caractere | Alt + |
|---|---|
| `║` | Alt + 186 |
| `═` | Alt + 205 |
| `╔` | Alt + 201 |
| `╗` | Alt + 187 |
| `╚` | Alt + 200 |
| `╝` | Alt + 188 |
| `│` | Alt + 179 |
| `─` | Alt + 196 |
| `┌` | Alt + 218 |
| `┐` | Alt + 191 |
| `└` | Alt + 192 |
| `┘` | Alt + 217 |

---

## Dica mais fácil

Copia daqui e salva num bloco de notas como sua **biblioteca pessoal**:
```
╔ ═ ╗ ║ ╚ ╝
┌ ─ ┐ │ └ ┘
╭ ─ ╮ │ ╰ ╯
╒ ═ ╕ │ ╘ ╛
╓ ─ ╖ ║ ╙ ╜
+ - |
```
